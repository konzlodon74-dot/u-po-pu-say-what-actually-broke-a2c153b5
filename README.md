A tiny Python program (standard library only) that writes one line of honest
error copy to `/output/entry.txt`. The line tells the user the brutal truth —
the server ran out of memory mid-save, so their work is genuinely gone — and
then punctures the usual corporate softening by refusing to call it
"temporarily unavailable" and warning that refreshing will not resurrect it.
It names the real failure, says what to expect next (nothing is coming back),
and lands the joke in a single line a team could actually ship in a dialog.

Run it with `python3 main.py`.
